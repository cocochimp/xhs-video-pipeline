# 口播与审核标准（全局）

AI 写文本、写分镜后，先按这份标准自查并自己改掉问题，再交给人审。
程序能检查的部分由 `studio/review.py` 自动检查；检查不过就把问题交回 AI 修，最多两轮。

## 一、口播节奏

方法来自播音的「气口」和「停连」：观众要有时间听懂一句再听下一句，靠的是**短句 + 停顿**，不是放慢每个字。

1. **一句只说一件事**：每句朗读不超过 18 个字；超过就拆成两句。
2. **句间留一点气口**：同一片内句子之间只多停 0.08 秒，换片多停 0.18 秒，听感是「换口气」而不是「停下来」（`studio/config.json` 的 `pace`，所有期统一）。停顿宁短勿长，整体要紧凑。
3. **重点前停一下**：要强调的数字或结论单独成句，前面一句用逗号或冒号结尾，例如「答案是：」「结果呢，」。
4. **问句后给答案前要停**：设问句后面紧跟的答案另起一句。
5. **数字写成汉字、读得顺**：「一千块」不写「1000块」；大数字单独一句。
6. **语速**：全局语速在音效库调（现在 +25）；节奏优先靠停顿解决，不靠整体变慢。

## 二、语气统一

全片都是阿牛在跟一个朋友聊天：第一人称或第二人称、口语、不端着。

1. **不切换身份**：不能突然变成主持人或客服口吻（如「评论区说说」「欢迎留言」「感谢收看」）。
2. **结尾互动用阿牛的口吻**：问题写成聊天，例如「你会先试哪一件？留言告诉阿牛」。
3. **结尾的提问放在正文里一起配音**（seg=body）：`end` 段只放固定口号「关注阿牛，一起早日退休！」。分开合成会让语气断掉。
4. **不用书面词**：「因此」「此外」「综上所述」「首先其次」换成「所以」「还有」「说白了」。

## 三、画面

1. **不画多余的装饰线**：卡片、路牌下面不加木杆、连接线、分隔线；背景只有纸张和点阵。
2. **不重叠**：卡片、大字、道具不压阿牛的脸，也不互相压；底部 y>960 留给字幕，顶部 y<90 留给进度条。
3. **一片一只阿牛**：换姿势时前一个先消失。
4. **姿势和道具全期不重复**（同一片内除外）。
5. **音效少而准**：每分钟最多 8 个，只放在关键数字和结论上。

## 四、内容

1. 至少 60 秒；清单类每一条都讲完整，不灌水。
2. 痛点 → 要点 → 结论 + 一个能照做的动作。
3. 每期最多一个核心数字。
