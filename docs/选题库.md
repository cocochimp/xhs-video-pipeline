# 阿牛要退休 · 选题库

「阿牛要退休」是人设和目标：一个想早点退休的打工牛马。每期讲的是打工人每天碰到的钱和认知问题，不只算退休。
每期独立成篇，不做连续剧；发一期在视频顶部进度条记一期（第 x/100 期）。

## 内容比例

| 类别 | 占比 | 讲什么 |
|---|---|---|
| 搞钱 | 40% | 涨薪、跳槽、副业、技能变现，让收入变多 |
| 认知 | 30% | 思维方式和消费陷阱，看清钱是怎么没的 |
| 理财基础 | 20% | 工资条、应急金、利率、复利，能直接照做的常识 |
| 退休 / FIRE | 10% | 4% 法则、退休数字，阿牛的主线 |

选题要有普适性：从加班、跳槽、月光、被裁、攒不下钱这些打工人日常出发，结论落到一个能照做的动作。

## 每期固定结构（60～75 秒，约 330～400 字）

1. 顶部进度条：`阿牛FIRE计划 ▓▓░░ x/100`（全片常驻）
2. 开头（约 8 秒）：钩子「普通人，要如何才能提前退休？」→「这里是阿牛退休计划，第 x 期」→「本期我们要讲的是：<选题>」（选题滚动）
3. 正文（约 50～60 秒）：痛点 → 3 个要点（清单 / 对比 / 算一笔账）→ 结论 + 一个能照做的动作
4. 结尾（约 5 秒）：「关注阿牛，一起早日退休！」+ 小字「虚拟角色·模拟测算·不构成投资建议」

## 优先发（具体数字 + 痛点 + 清单）

- 月薪8千到手四千？入职必看的工资条
- 除了打工，普通人还能靠这5件事搞钱
- 为什么越努力越穷？3个看不见的漏钱口
- 涨薪谈判：开口前准备这3样
- 外卖vs带饭：一个月差多少钱
- 月薪8千，想退休到底要攒多少钱？

## 搞钱（40%）

### 涨薪与跳槽
- 涨薪谈判：开口前准备这3样
- 跳槽涨薪多少才值得
- 工作3年还在原地？职场的复利
- 为什么老员工工资不如新人
- 大厂vs国企vs小公司：一笔经济账
- 35岁危机：现在就该准备什么
- 被裁员了：N+1怎么算，别吃亏
- 刚毕业第一份工作怎么选才不亏
- 年终奖怎么谈、怎么拿
- 绩效考核的潜规则：怎么让老板看见你

### 副业与技能变现
- 副业的真相：大部分人赚不到钱
- 先卖你上班已经会的技能
- 5个低成本副业方向，适合哪些人
- 时间换钱vs作品换钱
- 个人技能怎么定价
- 副业要不要辞职做？先算这笔账
- 副业避坑：交钱学赚钱的都要小心
- 下班2小时，怎么变成第二份收入
- 做内容能赚钱吗：普通人的起步路线
- 接私活怎么报价、怎么收款

### 搞钱思维
- 普通人的赚钱公式：单价 × 数量 × 时间
- 为什么打工很难致富：收入的天花板
- 被动收入到底存不存在
- 赚第一个1万块，比想象中难在哪
- 收入越多越要警惕：生活方式膨胀

## 认知（30%）

- 为什么越忙越穷
- 机会成本：你以为省了，其实亏了
- 沉没成本：花了钱就一定要用完吗
- 消费主义的3个话术
- 大促的5个套路，越买越亏
- 订阅制陷阱：自动续费偷走多少钱
- 无效节俭：这些钱省了反而亏
- 面子消费：为别人的眼光买单
- 延迟满足：想买的东西先放30天
- 复利不只在钱上：技能和人脉也有复利
- 为什么穷人更容易被割韭菜
- 信息差就是钱：普通人怎么补
- 长期主义：为什么不要梭哈
- 贵人为什么愿意拉你一把
- 焦虑的时候最容易乱花钱
- 存钱是能力，不是性格

## 理财基础（20%）

- 看懂工资条：税前1万到手多少
- 五险一金分别是什么，交了亏不亏
- 公积金不只是买房才能用
- 个税专项附加扣除：这几项别漏填
- 应急金存几个月才够？按你的工作算
- 花呗白条分期：利率到底多高
- 信用卡最低还款的坑
- 复利：为什么越早开始越好
- 通胀：放在银行的钱每年在缩水
- 记账一周，钱都去哪了
- 工资到手先做这3件事
- 房租占工资多少才合理
- 识别投资骗局的5个信号
- 荐股群、带单老师：为什么都是坑

## 退休 / FIRE（10%）

- 月薪8千，想退休到底要攒多少钱？
- FIRE计划是什么？2分钟讲清
- 4%法则：退休要攒够多少钱
- 存钱率决定一切：存30%和存50%差了10年
- 存款100万，每月能有多少被动收入
- 每年涨薪2%和不涨，退休差几年
- 提前退休后，社保和医保怎么办
